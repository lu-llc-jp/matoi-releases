# matoi-releases

**matoi（纏）** の配布用リポジトリです。ローカルの複数開発プロジェクトを一望し、dev サーバーの起動/停止を管制する macOS 向けデスクトップアプリです。

このリポジトリには**配布物（ビルド済みバイナリ）だけ**を置いています。ソースコードはここにはありません。

## 動作環境

- macOS（**Apple Silicon 専用**。Intel Mac では動作しません）

## インストール

1. [Releases](https://github.com/lu-llc-jp/matoi-releases/releases/latest) から最新の `.dmg` をダウンロードします。
2. `.dmg` を開き、`matoi.app` を「アプリケーション」フォルダへドラッグします。

### 初回起動時の警告について

matoi は Apple の公証を受けていないため、初回起動時に「"matoi" は開いていません」という警告が表示されます。次の手順で開いてください。

1. 警告で「完了」を押して閉じます（「ゴミ箱に入れる」は押さないでください）。
2. 「システム設定」→「プライバシーとセキュリティ」を開き、下部に表示される matoi の項目で「このまま開く」を押します。
3. 確認ダイアログで「このまま開く」を押し、パスワードまたは Touch ID で認証します。

許可は一度だけ必要です。

## アップデート

2 回目以降のアップデートは、アプリの**設定画面**から「アップデート」の「確認する」→ ダウンロード →「再起動して適用」の順で行えます。改めて `.dmg` をダウンロードする必要はありません。
