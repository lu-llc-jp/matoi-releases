# matoi-releases

**matoi（纏）** の配布用リポジトリです。ローカルの複数開発プロジェクトを一望し、dev サーバーの起動/停止を管制する macOS 向けデスクトップアプリです。

このリポジトリには**配布物（ビルド済みバイナリ）だけ**を置いています。ソースコードはここにはありません。

## 動作環境

- macOS（**Apple Silicon 専用**。Intel Mac では動作しません）

## インストール

1. [Releases](https://github.com/lu-llc-jp/matoi-releases/releases/latest) から最新の `.dmg` をダウンロードします。
2. `.dmg` を開き、`matoi.app` を「アプリケーション」フォルダへドラッグします。

### 初回起動時の警告について

matoi は Apple の署名・公証を受けていないため、初回起動時に「開けません」「開発元を検証できません」といった警告が表示されます。次のいずれかの方法で開いてください。

- **システム設定から許可する**: 一度 `matoi.app` を開こうとして警告を閉じたあと、「システム設定」→「プライバシーとセキュリティ」を開き、下部に表示される matoi の項目で「このまま開く」を押します。
- **Control+クリックで開く**（古い macOS の場合）: Finder で `matoi.app` を Control+クリック（または右クリック）→「開く」を選び、ダイアログで「開く」を押します。
- **ターミナルから隔離属性を外す**:
  ```sh
  xattr -dr com.apple.quarantine /Applications/matoi.app
  ```

許可は一度だけ必要です。

## アップデート

2 回目以降のアップデートは、アプリの**設定画面**から「アップデート」の「確認する」→ ダウンロード →「再起動して適用」の順で行えます。改めて `.dmg` をダウンロードする必要はありません。
